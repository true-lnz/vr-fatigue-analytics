# Запуск Live-сценария

## Подготовка один раз

1. Установить Python и зависимости командой `python -m pip install -r backend\requirements.txt`.
2. Запустить Emotiv Launcher, включить виртуальный EPOC X и дождаться статуса `connected`.

## Запуск перед показом

1. Откройте обычную **Командную строку (CMD)** в корне проекта.
2. Выполните `start-live.cmd`.
3. В консоли сервера дождитесь подключения Cortex. В ней доступны вкладки: `1` статус, `2` Cortex, `3` сессии, `4` логи; `d` выводит отладку, `q` завершает сервер.
4. Откройте Unity-проект `unity\VR Fatigue Analytics`.
5. Откройте сцену `Assets/OperatorTest.unity`, нажмите **Play**, затем **Начать тест**.
6. Пройдите тест 60 секунд. Результат появится в Unity.

## Что показать на защите

- задания и таймер в Unity;
- строку `Live Cortex subscribed` в сервере;
- экран результата Unity с источником `live` и количеством `emotiv_samples`;
- строку `session_result` в окне сервера.

Для запуска готового приложения можно выполнить `start-defense.cmd`. Он открывает
Live backend и собранное Windows-приложение Unity.

Если CMD сообщает, что порт `8765` занят, сервер уже работает — вторую копию запускать не надо.

Результаты сессий сохраняются в `logs/backend.jsonl`. Диагностические Python-модули в `backend/` в обычном показе не запускаются.
