# Факты о среде разработки

Дата проверки: 2026-11-05.

## Обнаружено автоматически

- Windows 10 x64.
- Python 3.10.11 доступен через команду `python`.
- Unity CLI 1.0.0-beta.13 доступен.
- Установлен Unity 6.6.8f1: `C:\Program Files\Unity\Hub\Editor\6000.6.8f1\Editor\Unity.exe`.
- Также установлены Unity 2020.3.49f1 и 2019.3.3f1.
- Emotiv Launcher и процессы `CortexService`/`CortexSync` запущены.
- Пакеты Python `websockets`, `websocket-client` и `cortex` пока не установлены.

## Ограничения

- Старый batch-тест Unity указывал на отсутствующий проект и завершался ошибкой лицензии.
- Основной проект Unity в корне репозитория ещё не создан.
- Поля Performance Metrics Emotiv пока не подтверждены подписанным сообщением Cortex.
- Read-only discovery Cortex выполнен 2026-11-05: версия 4.13.5.3, виртуальный EPOC X найден и имеет статус `connected`.

## Решение для первого прохода

Рабочий сценарий проекта использует Live-подключение Cortex. Для запуска применяется `start-live.cmd`; параметры локального Cortex-приложения заданы в `backend/live_config.py`.

## Что нужно проверить вручную

1. Войти в EMOTIV Launcher.
2. Активировать виртуальное устройство EPOC X.
3. Открыть Cortex API Explorer или другой доступный клиент.
4. Подтвердить, приходит ли поток `met`, и сохранить 30–60 секунд JSON-сообщений без токенов и секретов.

Результат этой проверки будет добавлен в `docs/EMOTIV_SETUP.md` до включения Live-адаптера в расчёт.
