## Зафиксированные решения

- Базовая демонстрация работает как настольная 3D-сцена без VR-шлема.
- Unity моделирует взгляд через camera raycast и события фиксации.
- Emotiv используется как источник доступных Performance Metrics; сырые EEG остаются отдельным расширением.
- Python является центром агрегации, расчёта индекса и WebSocket-обмена.
- Unity содержит весь пользовательский интерфейс; Python возвращает данные, состояния и результат.
- Первое вычисление выполняется после завершения 60-секундной сессии.
- Live использует единую схему сообщений между Unity и Python.
