# Короткая шпаргалка для защиты

## Запуск

1. Открыть Emotiv Launcher и включить виртуальный EPOC X.
2. В CMD из корня проекта выполнить `start-live.cmd`.
3. В консоли сервера открыть вкладку `2 CORTEX` и проверить, что растёт `Received met samples`.
4. В Unity открыть `Assets/OperatorTest.unity`, нажать **Play** и **Начать тест**.

## Что объяснить

- Unity проводит простой тест внимания и собирает реакции, ошибки, пропуски и виртуальные фиксации взгляда.
- Python получает эти события через локальный WebSocket.
- Python параллельно получает поток `met` от Cortex API.
- После `session_finish` backend усредняет признаки и считает прозрачный эвристический индекс от 0 до 1.
- Unity показывает индекс, категорию и исходные признаки.

## Если спросят про ограничения

Это учебный прототип. Виртуальный EPOC X не является клиническим измерением, а взгляд моделируется в Unity. Индекс не является медицинским диагнозом.

## Команды консоли

`1` статус, `2` Cortex, `3` сессии, `4` логи, `d` отладка, `q` остановка. Вкладки также можно нажимать мышью.

## Контроль перед показом
Проверить запуск Unity, соединение с локальным backend и наличие итогового экрана после завершения смены.
