# Короткий runbook

1. Запустить Emotiv Launcher и виртуальный EPOC X.
2. В CMD из корня проекта выполнить `start-live.cmd`.
3. В консоли сервера открыть Cortex logs (`3`) и дождаться входящих метрик.
4. Запустить Unity, открыть `Assets/OperatorTest.unity`, нажать **Play**.
5. Нажать **Начать тест** и пройти 60 секунд.
6. Показать экран результата и строку `session_result` в CMD.

Сервер принимает сообщения Unity на `ws://127.0.0.1:8765`. При занятом порте
второй экземпляр запускать не нужно.

## Управление консолью

Порядок вкладок: `1` Status, `2` Server Logs, `3` Cortex logs (realtime),
`4` Sessions, `5` Exit. Доступны клавиши `1`–`5` и мышь. В журналах
стрелки или `w`/`s` прокручивают строки, `Home`/`End` переходят в начало или
конец. При просмотре старых строк новые записи не меняют позицию просмотра.
Ошибки, предупреждения и информационные сообщения имеют разные цвета и русские
метки в разделе `Server Logs`.
