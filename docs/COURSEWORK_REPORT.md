# Система оценки признаков утомления оператора в виртуальной диспетчерской

## Аннотация

Разработан настольный учебный прототип, объединяющий поведенческие показатели оператора, моделируемые признаки взгляда и Performance Metrics Emotiv. Unity проводит 60-секундную смену диспетчера городской энергосети. Python принимает игровые события и поток Cortex `met`, рассчитывает объяснимый интегральный индекс признаков утомления и формирует отчёт HTML по каждой завершённой сессии.

## Цель и задачи

Цель — реализовать прототип сбора нескольких типов признаков состояния оператора в виртуальной рабочей среде. Для этого созданы игровые сцены, WebSocket-контракт Unity–Python, соединение с Cortex API, агрегирование событий сессии и экран результатов.

## Состав системы

- **Unity**: главное меню, смена оператора, экран результата; задания по устранению аварий энергосети; запись точности и реакции; симуляция взгляда наведением курсора на элементы UI.
- **Python**: локальный WebSocket-сервер, подключение к Cortex, сбор событий Unity, расчёт сводных признаков и HTML-отчёт.
- **Emotiv Cortex**: фактически подтверждённый поток `met` с полями `attention`, `eng`, `exc`, `lex`, `str`, `rel`, `int`.

## Игровой сценарий

Оператор обрабатывает тревоги на северной, южной и резервной линиях. Смена длится 60 секунд и делится на стабильную фазу, повышенную нагрузку и кризисный пик. Для ложного сигнала доступно действие «Игнорировать». Истечение лимита фиксируется как пропуск. Unity регистрирует правильность ответа и время реакции.

## Методы расчёта

Поведенческий компонент объединяет среднюю реакцию, ошибки, пропуски и поздние ответы. Gaze-компонент использует среднюю длительность фиксации, разброс наведения и отвлечения. Emotiv-компонент использует подтверждённые средние `eng` и `rel`; его вклад маркируется как эвристический. Итог ограничивается диапазоном `[0, 1]`:

`index = 0.55 × behavior + 0.25 × gaze + 0.20 × emotiv`

Категории прототипа: `low` ниже 0.34, `medium` от 0.34 до 0.67, `high` от 0.67. По игровым событиям дополнительно рассчитываются показатели по трём фазам. Эти пороги и веса не обучались на клинической выборке.

## Результаты реализации

Проект содержит сцены главного меню, операторской смены и результатов. Unity соединяется с backend по `ws://127.0.0.1:8765`. Завершённая сессия сохраняется в `logs/backend.jsonl`, а индивидуальный HTML-отчёт формируется в `reports/`.

Фактические численные результаты эксперимента следует заполнять только после прохождения теста с подключённым Cortex. Прототип не подставляет вымышленные данные при отсутствии сессии.

## Ограничения и вывод

Используется виртуальное устройство EPOC X; его значения не являются клиническими измерениями. Взгляд оценивается по наведению мыши и не является настоящей окулографией. Индекс — прозрачная эвристика, а не медицинский диагноз и не валидированная модель. Реализованный прототип демонстрирует технический цикл получения и анализа поведенческих, gaze- и Emotiv-признаков в Unity и Python.
