# Контекст курсового проекта

## Рабочее название

**Система предиктивной аналитики усталости оператора в виртуальной среде с использованием метрик Emotiv, окулографических и поведенческих признаков**.

Практический результат — учебный прототип, а не медицинская диагностическая система.

## Условия и ограничения

- Разработка ведётся в Unity на уровне простого 3D-приложения.
- VR-шлема и отдельного eye-tracker нет.
- У пользователя есть Emotiv Launcher и виртуальное устройство EPOC X.
- Реальный рабочий канал Emotiv должен быть проверен до реализации зависимых частей.
- Окулография в базовом режиме моделируется в Unity.
- Обмен между Unity и Python выполняется через локальный WebSocket.
- Unity является единственным пользовательским приложением: стартовое окно, ход теста и окно результатов находятся в Unity.
- Python является локальным аналитическим backend и не рисует пользовательский интерфейс.
- Для защиты используется один рабочий режим Live с виртуальным EPOC X.

## Идея продукта

Unity запускает короткий тест оператора. На виртуальной панели появляются задачи, пользователь отвечает кнопками, а приложение записывает время реакции, ошибки, пропуски и виртуальный взгляд. Python параллельно принимает метрики Emotiv и события Unity. После завершения теста Python агрегирует данные, рассчитывает интегральный индекс признаков утомления, присваивает категорию и отправляет результат обратно в Unity.

## Границы первой версии

### Обязательно

1. Настольная 3D-сцена от первого лица.
2. Тест продолжительностью 60 секунд с понятным завершением.
3. Операторская панель и задания на внимание.
4. Запись поведения пользователя.
5. Виртуальный поток окулографических признаков.
6. Приём фактически доступных Performance Metrics Emotiv через Cortex API.
7. Python-сервис с WebSocket.
8. Итоговый индекс и три категории состояния.
9. Отображение результата в Unity.

### Отложено

- обработка сырых EEG-каналов;
- настоящая окулография;
- онлайн-адаптация сложности во время первого теста;
- сложная нейросеть;
- запуск на VR-шлеме;
- медицинская интерпретация результата.

## Научная оговорка

Performance Metrics Emotiv, поведенческие показатели и синтетическая окулография являются признаками прототипа. Их комбинация не доказывает наличие клинической усталости. В отчёте результат называется **интегральным индексом признаков утомления** или **оценкой состояния прототипа**.
