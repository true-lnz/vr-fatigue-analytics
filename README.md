# VR Fatigue Analytics

**Тема курсовой работы:** «Система предиктивной аналитики усталости оператора в виртуальной среде с использованием метрик Emotiv, окулографических и поведенческих признаков».

## О проекте

Основная идея проекта заключается в проведении короткой операторской смены в Unity и последующем расчёте интегрального индекса признаков утомления.

Оператор управляет виртуальной диспетчерской энергосети, реагирует на аварийные события и выбирает нужные районы на физических кнопках консолей. Python принимает события Unity и метрики Cortex, агрегирует данные и возвращает подробный результат анализа.

Система использует три группы признаков:

- **Поведенческие** — время реакции, ошибки, пропуски и поздние ответы;
- **Окулографические** — виртуальные фиксации, разброс взгляда и отвлечения;
- **Emotiv Performance Metrics** — фактически доступные показатели потока `met`.

Результат является учебной эвристической оценкой состояния прототипа и не предназначен для медицинской диагностики.

## Архитектура системы

Основная последовательность обработки данных:

```text
EMOTIV Launcher / Virtual EPOC X
              |
              v
       Cortex API / met
              |
              v
      Python Neuro Service
              ^
              | WebSocket / JSON
              v
       Unity Operator Test
              |
      поведение + virtual gaze
              |
              v
      SessionResultStore
              |
              v
       Экран полного отчёта
```

Unity отвечает за весь пользовательский поток: главное меню, сцену смены, управление консолями, таймер, визуальные состояния и экран результата.

Python отвечает за подключение к Cortex, сбор и агрегацию событий, расчёт индекса, запись журнала и создание HTML-отчёта.

## Сценарий операторской смены

Тест длится **60 секунд** и состоит из трёх фаз:

1. стабильная работа;
2. повышенная нагрузка;
3. кризисный пик.

В сцене доступны три зоны управления:

- северный район;
- резервный район;
- южный район.

На консолях отображаются анимированные экраны, индикаторы нагрузки и аварийные состояния. Проблемный район выделяется красной подсветкой и мигающим аварийным маяком.

## Аналитический индекс

Backend объединяет признаки в прозрачную эвристику:

```text
behavior_component = reaction_time + errors + missed_targets
                    + late_responses

gaze_component     = fixation + dispersion + distractions

emotiv_component   = доступные Performance Metrics Emotiv

fatigue_score      = weighted sum of components, clamped to [0, 1]
```

Категории прототипа:

- `low` — низкая нагрузка;
- `medium` — средняя нагрузка;
- `high` — высокая нагрузка.

Пороговые значения и веса не обучались на клинической выборке.

## Запуск проекта

### Подготовка

1. Установить Unity Hub и Unity Editor версии **6000.6.8f1**.
2. Установить Python 3.10 или новее.
3. Установить зависимости:

```bash
python -m pip install -r backend/requirements.txt
```

4. Запустить EMOTIV Launcher и включить виртуальный EPOC X.

### Запуск готового приложения

В корне проекта выполнить:

```text
start-defense.cmd
```

Скрипт запускает Python backend и актуальную Windows-сборку Unity:

```text
unity/VR Fatigue Analytics/Build/VRFatigueAnalytics_Updated.exe
```

### Запуск через Unity Editor

1. Открыть проект `unity/VR Fatigue Analytics`.
2. Открыть сцену `Assets/MainMenu.unity` или `Assets/OperatorTest.unity`.
3. Нажать **Play**.
4. Дождаться подключения backend.
5. Запустить смену.

Для обновления Windows-сборки используется метод `PrototypeBuilder.BuildWindows()`.

## Управление

| Клавиши / действие | Назначение |
|---|---|
| `W / A / S / D` | Перемещение по диспетчерской и карте |
| Движение мыши | Поворот камеры |
| `Tab` | Режим интерактивной карты |
| Левая кнопка мыши | Выбор линии на карте или физической кнопки |
| `Enter` | Подтверждение выбранного действия |
| `Esc` после завершения | Переход к результатам |
| Центральный крестик | Прицел камеры |

Физические кнопки расположены непосредственно возле консолей соответствующих районов. Выбор можно менять до подтверждения клавишей `Enter`.

## Данные и результаты

Журнал событий backend сохраняется в:

```text
logs/backend.jsonl
```

HTML-отчёты по завершённым сессиям сохраняются в:

```text
reports/
```

Unity отображает полный отчёт с индексом, категорией, временем реакции, ошибками, пропусками, фиксациями, отвлечениями и количеством метрик Emotiv.

## Текущий статус

Реализованы:

- настольная 3D-сцена диспетчерской;
- 60-секундный операторский тест;
- перемещение по сцене через WASD;
- интерактивная карта районов;
- физические кнопки возле консолей;
- подтверждение действия через `Enter`;
- анимации экранов и консолей;
- аварийная подсветка проблемного района;
- мигающий красный аварийный маяк;
- моделируемая окулография;
- WebSocket-обмен Unity–Python;
- подключение Live Cortex;
- полный экран результата и HTML-отчёт.

## Ограничения

- виртуальный EPOC X не является клиническим измерительным устройством;
- взгляд моделируется в Unity и не является настоящей окулографией;
- итоговый индекс является объяснимой эвристикой;
- результат не является медицинским диагнозом;
- сырые EEG-каналы и настоящий eye-tracker не используются в первой версии.

## Назначение

Проект предназначен для учебной демонстрации полного цикла сбора и анализа поведенческих, виртуальных окулографических и Emotiv-признаков в Unity и Python.
